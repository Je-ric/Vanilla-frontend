How to Read

Columns

H1 H2 = Hour tens & ones

M1 M2 = Minute tens & ones

S1 S2 = Second tens & ones

Rows (top → bottom)

Row 1 = bit value 8

Row 2 = bit value 4

Row 3 = bit value 2

Row 4 = bit value 1

Example: 10:20:35

H1=1 (0001), H2=0 (0000) → 10

M1=2 (0010), M2=0 (0000) → 20

S1=3 (0011), S2=5 (0101) → 35
